# Папка `audio/` — треки Suno

Сюда кладутся MP3-файлы, сгенерированные в Suno. Сайт сам подхватит их — никакой код менять не нужно.

## Именование

```
<id уровня, 3 цифры>_<slug>_<номер варианта>.mp3
```

Примеры: `020_shame_1.mp3`, `020_shame_2.mp3`, `200_courage_3.mp3`, `700_enlightenment_1.mp3`.

Точный список ожидаемых файлов для каждого уровня — в поле `tracks` в `data/tracks.json`
(и в разделе «Файлы» в `SUNO_PROMPTS.md`). По умолчанию у уровней 200, 350 и 500 — по 3 варианта,
у остальных — по 2.

| id | slug | id | slug |
|---|---|---|---|
| 020 | shame | 250 | neutrality |
| 030 | guilt | 310 | willingness |
| 050 | apathy | 350 | acceptance |
| 075 | grief | 400 | reason |
| 100 | fear | 500 | love |
| 125 | desire | 540 | joy |
| 150 | anger | 600 | peace |
| 175 | pride | 700 | enlightenment |
| 200 | courage | | |

## Как это работает

* Если вариантов несколько, при каждом заходе на уровень выбирается случайный (кнопка ⇄ в плеере переключает вариант).
* Если файла нет — плеер пробует другой вариант, а если нет ни одного, показывает «Трек ещё не загружен»
  и сразу открывает кнопку «Я выполнил практику». Поэтому сайт можно публиковать до того, как готова вся музыка.
* Хотите больше или меньше вариантов — просто поправьте массив `tracks` у нужного уровня в `data/tracks.json`
  и запустите `python3 tools/build.py`.

## Размер

GitHub принимает файлы до 100 МБ, а репозиторий для Pages желательно держать до ~1 ГБ.
MP3 из Suno (~3–5 МБ на трек) × 40 треков ≈ 150–200 МБ — укладывается с запасом.
Рекомендуемый битрейт: 192 kbps.
