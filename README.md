# Шкала Хокинса: Восхождение

Интерактивная музыкальная практика на основе «Карты сознания» Дэвида Хокинса.
Шкала — 17 уровней от **20 · Стыд** до **700+ · Просветление**. Пользователь начинает с того уровня,
который соответствует его состоянию сейчас (хоть с самого верха), и поднимается выше, слушая треки,
созданные в Suno (стиль Enigma), и проживая тексты-практики. Статический сайт для GitHub Pages:
чистые HTML / CSS / JavaScript, без сборки и зависимостей.

## Возможности

* **«Где вы сейчас?»** — при первом входе открывается выбор стартового уровня: все 17 уровней с коротким
  описанием состояния. Можно начать с любого. Кнопка «⇅ Сменить уровень» / «Выбрать своё состояние»
  на карте позволяет в любой момент перевыбрать уровень вверх или вниз (с подтверждением).
* **Все уровни ниже текущего открыты** — для практики и прослушивания в любой момент (состояние может опускаться);
  подъём выше текущего — по-прежнему шаг за шагом.
* **Карта** (`index.html`) — вертикальная шкала 20 → 700+, текущий уровень светится, закрытые — серые,
  кнопка «Начать практику», прогресс «Пройдено N из 17».
* **Практика** (`level.html?id=N`) — плеер, практика дня, аффирмация, полный текст песни.
  «Завершить уровень» активируется после полного прослушивания трека **или** после кнопки «Я выполнил практику»
  (она открывается после 60 секунд прослушивания либо сразу, если трек ещё не загружен).
* **Восхождение** — после завершения: переход на карту со вспышкой и спиралью искр, новый уровень подсвечивается.
* **Библиотека** (`library.html`) — архив пройденных уровней и всех уровней ниже текущего, каждый можно переслушать; вариант трека выбирается случайно.
* **Несколько треков на уровень** — массив `tracks` в `data/tracks.json`, случайный выбор, кнопка ⇄ «другой вариант».
* **Ежедневность** (выключена по умолчанию) — следующий уровень открывается через 24 часа после завершения предыдущего.
* **Сброс прогресса** — внизу карты.
* Прогресс в `localStorage`: `hawkins_progress` = id текущего уровня (выбирается при первом входе;
  если ничего не сохранено — по умолчанию `20`), `hawkins_history` — когда завершён каждый уровень,
  `hawkins_picked_at` — время ручного выбора уровня (сбрасывает суточный отдых «Ежедневности»).
  Старые сохранения работают как раньше — окно выбора им не показывается.
* Полная адаптация под телефон, тёмная тема, сакральная геометрия (SVG «Цветок жизни» + гексаграмма).

## Структура

```text
/
├── index.html          Карта (главная)
├── level.html          Страница практики (?id=20 … ?id=700)
├── library.html        Библиотека пройденных треков
├── css/style.css
├── js/app.js           Прогресс, карта, уровни, библиотека, таймер
├── js/player.js        Аудиоплеер (случайный вариант, fade, обработка отсутствующих файлов)
├── audio/              MP3 из Suno (см. audio/README.md)
├── data/tracks.json    Все уровни: названия, тема, практика, стиль Suno, тексты, пути к трекам
├── data/tracks.js      Копия tracks.json для открытия сайта без сервера (генерируется)
├── tools/build.py      Пересобирает tracks.js и SUNO_PROMPTS.md из tracks.json
├── SUNO_PROMPTS.md     Готовые промпты (Style + Lyrics) для каждого уровня
└── .nojekyll
```

## 1. Музыка (Suno)

1. Откройте `SUNO_PROMPTS.md`. Для каждого уровня скопируйте **Style of Music** и **Lyrics** в Suno (Create → Custom).
2. Сгенерируйте 1–3 варианта, скачайте MP3.
3. Переименуйте по схеме из `audio/README.md` (например, `150_anger_1.mp3`) и положите в `audio/`.

Тексты и стили можно менять в `data/tracks.json`; после правок запустите `python3 tools/build.py`,
чтобы обновить `data/tracks.js` и `SUNO_PROMPTS.md`.

## 2. Локальный просмотр

```bash
cd hawkins-scale-journey
python3 -m http.server 8000
# открыть http://localhost:8000
```

(Двойной клик по `index.html` тоже работает — данные подхватятся из `data/tracks.js`.)

## 3. Публикация на GitHub Pages

1. Создайте **публичный** репозиторий на GitHub, например `hawkins-scale-journey`.
2. Загрузите файлы:
   ```bash
   cd hawkins-scale-journey
   git remote add origin https://github.com/<username>/hawkins-scale-journey.git
   git branch -M main
   git push -u origin main
   ```
   (или через веб-интерфейс: **Add file → Upload files** и перетащить содержимое папки).
3. В репозитории: **Settings → Pages → Build and deployment → Source: Deploy from a branch**,
   ветка **main**, папка **/ (root)** → **Save**.
4. Через 1–2 минуты сайт будет доступен по адресу `https://<username>.github.io/hawkins-scale-journey/`.
5. Проверка по критериям приёмки: трек играет, прогресс сохраняется после перезагрузки,
   следующий уровень открывается только после действия на текущем.

Аудио лежит в том же репозитории и отдаётся с того же домена — проблем с CORS нет.
Все пути относительные, поэтому сайт работает в подпапке `/<repo>/` без настроек.

## Сброс / отладка

* Кнопка «Сбросить прогресс» внизу карты.
* Или в консоли браузера: `localStorage.clear()`.
* Сменить уровень: кнопка «⇅ Сменить уровень» в верхней карточке, тап по закрытому уровню на шкале («⇅ начать отсюда») или ссылка `index.html?pick=1`.
* Ассеты версионируются (`?v=...`) при каждом `python3 tools/build.py` — запускайте его перед коммитом, чтобы браузеры не брали старые JS/CSS из кэша.
* Снова увидеть окно первого входа: «Сбросить прогресс».
